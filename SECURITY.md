# Security policy

## Supported versions

Security fixes are provided for the current published release of MarifeX Advanced Analytics. Administrators should run the latest available release and a supported GLPI version.

| Version | Supported |
|---|---|
| 0.15.2 | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [mohammed@marifextech.com](mailto:mohammed@marifextech.com).

Include the following information when available:

- affected MarifeX and GLPI versions
- affected endpoint or component
- steps required to reproduce the issue
- observed and expected behaviour
- potential security impact
- relevant logs or screenshots with credentials and personal data removed

Do not disclose an unresolved vulnerability through a public GitHub issue. MarifeX will review the report, confirm whether additional information is required, and coordinate remediation and responsible disclosure with the reporter.

## Security scope

Reports concerning authentication, authorisation, entity isolation, data exposure, report access, unsafe input handling, dependency risk or privilege escalation are in scope.

General support questions and feature requests should be sent to the same contact with a clear description of the request.
